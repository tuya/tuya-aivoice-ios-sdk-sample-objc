# 涂鸦对接绿联云端接口

通过涂鸦云端 API 调用绿联云端能力。iOS 调用方式统一使用 `ThingSmartRequest`，Android 通过 `Business().asyncRequest` / `Business().asyncArrayList` 调用。

## 获取翻译语言列表

`m.wearable.audio.translate.lang.list`

**iOS**

```objectivec
NSDictionary *postData = @{@"source": @[@"asr-llm"]};
[[ThingSmartRequest new] requestWithApiName:@"m.wearable.audio.translate.lang.list"
                                  postData:postData
                                   version:@"1.0"
                                   success:^(id result) {
    // result 包含语言列表
} failure:^(NSError *error) {
    // 请求失败
}];
```

**Android**

```kotlin
val apiParams = ApiParams("m.wearable.audio.translate.lang.list", "1.0").apply {
    putPostData("source", arrayOf("asr-llm")) // 或 arrayOf("asr-llm-tts")
}
Business().asyncArrayList(
    apiParams,
    LangBean::class.java,
    object : ResultListener<ArrayList<LangBean>> {
        override fun onFailure(bizResponse: BusinessResponse?, bizResult: ArrayList<LangBean>?, apiName: String?) {}
        override fun onSuccess(bizResponse: BusinessResponse?, bizResult: ArrayList<LangBean>?, apiName: String?) {}
    }
)
```

| 参数       | 类型           | 说明                                                  |
| -------- | ------------ | --------------------------------------------------- |
| apiName  | NSString     | `m.wearable.audio.translate.lang.list`              |
| postData | NSDictionary | `@{@"source": @[@"asr-llm"]}` 或 `@[@"asr-llm-tts"]` |
| version  | NSString     | 1.0                                                 |

source 可选值：

| asr-llm     | 仅 ASR + LLM 能力 |
| ----------- | -------------- |
| asr-llm-tts | 含 TTS 能力       |

返回结构：`result` 为语言对象数组。

| 字段             | 类型       | 说明              |
| -------------- | -------- | --------------- |
| code           | NSString | 语言编码，如 zh、en、ja |
| selfDescribing | NSString | 语言展示名称          |

返回示例

```json
[
  { "selfDescribing": "中文（简体）", "code": "zh" },
  { "selfDescribing": "English", "code": "en" },
  { "selfDescribing": "日本語", "code": "ja" },
  { "selfDescribing": "한국어", "code": "ko" },
  { "selfDescribing": "Deutsch", "code": "de" },
  { "selfDescribing": "Français", "code": "fr" },
  { "selfDescribing": "Русский", "code": "ru" },
  { "selfDescribing": "ไทย", "code": "th" },
  { "selfDescribing": "Bahasa Indonesia", "code": "id" }
]
```

`m.wearable.summary.template.recommend.list.get`

```objc
[[ThingSmartRequest new] requestWithApiName:@"m.wearable.summary.template.recommend.list.get"
                                  postData:nil
                                   version:@"1.0"
                                   success:^(id result) {
    // result 包含模板列表
} failure:^(NSError *error) {
    // 请求失败
}];
```

**Android**

```kotlin
Business().asyncArrayList(
    ApiParams("m.wearable.summary.template.recommend.list.get", "1.0"),
    TemplateGroupBean::class.java,
    object : ResultListener<ArrayList<TemplateGroupBean>> {
        override fun onFailure(bizResponse: BusinessResponse?, bizResult: ArrayList<TemplateGroupBean>?, apiName: String?) {}
        override fun onSuccess(bizResponse: BusinessResponse?, bizResult: ArrayList<TemplateGroupBean>?, apiName: String?) {}
    }

```

| 参数       | 类型           | 说明                                               |
| -------- | ------------ | ------------------------------------------------ |
| apiName  | NSString     | `m.wearable.summary.template.recommend.list.get` |
| postData | NSDictionary | nil                                              |
| version  | NSString     | 1.0                                              |

返回结构：result 为分组数组，每个分组含模板列表。

外层字段：

| 字段      | 类型       | 说明          |
| ------- | -------- | ----------- |
| result  | NSArray  | 分组数组        |
| success | BOOL     | 请求是否成功      |
| status  | NSString | 状态，成功为 "ok" |

分组对象字段：

| 字段        | 类型       | 说明                                                                              |
| --------- | -------- | ------------------------------------------------------------------------------- |
| nodeCode  | NSString | 分组编码：recommend（推荐）、universal（通用）、content_interview（内容与访谈）、industry_expert（行业专家） |
| nodeName  | NSString | 分组名称，如「推荐」「通用」                                                                  |
| templates | NSArray  | 该分组下的模板列表                                                                       |

模板对象字段：

| 字段             | 类型        | 说明                                                        |
| -------------- | --------- | --------------------------------------------------------- |
| id             | NSString  | 模板 ID                                                     |
| templateCode   | NSString  | **模板编码，传给 processRecordTransferResult 的 templateCode 参数** |
| templateName   | NSString  | 模板名称，如「AI 智能匹配」「会议」「通用总结」                                 |
| templateDesc   | NSString  | 模板描述，如「AI根据内容自动选择」「提取纪要与待办」                               |
| icon           | NSString  | 模板图标 URL                                                  |
| sort           | NSInteger | 分组内排序，数字越小越靠前                                             |
| customize      | BOOL      | 是否自定义模板                                                   |
| needColorAdapt | BOOL      | 图标是否需要颜色适配                                                |
| objectKey      | NSString  | 图标对象 Key（用于缓存等）                                           |

## 文件详情与转写/总结/翻译查询接口

文件详情接口用于获取录音和 AI 任务状态；本文只记录文件详情、正式转写/译文和总结结果的查询接口，

⚠️ **注意：发起转写/总结/翻译 还是走SDK接口调用。**

### 1. 文件详情查询

`m.wearable.audio.record.detail.query`

查询指定录音的基础信息、云端音频文件信息、加密信息、标签以及转写/翻译/总结状态。

**iOS**

```objectivec
NSDictionary *postData = @{@"recordId": @"ej_PHONE_IMPORT00BIO7kN_1785149135723"};
[[ThingSmartRequest new] requestWithApiName:@"m.wearable.audio.record.detail.query"
                                  postData:postData
                                   version:@"1.0"
                                   success:^(id result) {
    // result.baseInfo / result.fileInfo / result.encryptionInfo
} failure:^(NSError *error) {
    // 请求失败
}];
```

**Android**

```kotlin
Business().asyncRequest(
    ApiParams("m.wearable.audio.record.detail.query", "1.0").apply {
        putPostData("recordId", "ej_PHONE_IMPORT00BIO7kN_1785149135723")
    },
    RecordDetailBean::class.java,
    object : ResultListener<RecordDetailBean> {
        override fun onFailure(bizResponse: BusinessResponse?, bizResult: RecordDetailBean?, apiName: String?) {}
        override fun onSuccess(bizResponse: BusinessResponse?, bizResult: RecordDetailBean?, apiName: String?) {}
    }
)
```

| 参数                | 类型       | 必填  | 说明                                     |
| ----------------- | -------- | --- | -------------------------------------- |
| apiName           | NSString | 是   | `m.wearable.audio.record.detail.query` |
| postData.recordId | NSString | 是   | 录音全局唯一 ID；后续 AI 接口通常作为 `key` 传入        |
| version           | NSString | 是   | `1.0`                                  |

返回字段：

| 字段               | 类型                         | 说明                  |
| ---------------- | -------------------------- | ------------------- |
| `baseInfo`       | NSDictionary               | 录音基础信息和 AI 状态       |
| `fileInfo`       | NSDictionary/null          | 云端音频文件信息；未同步完成时可能为空 |
| `encryptionInfo` | NSDictionary/null          | 音频加密信息              |
| `tags`           | NSArray<NSString *> / null | 录音标签                |

`baseInfo` 关键字段：

| 字段                        | 类型          | 说明                      |
| ------------------------- | ----------- | ----------------------- |
| `recordId`                | NSString    | 录音全局唯一 ID               |
| `deviceId`                | NSString    | 录音设备 ID；手机录音通常为 `PHONE` |
| `name`                    | NSString    | 文件名称                    |
| `recordTime`              | long        | 录制开始时间，毫秒时间戳            |
| `duration`                | int         | 录音时长，单位秒                |
| `syncStatus`              | int         | 云端音频同步状态                |
| `transcriptionStatus`     | int         | 正式转写状态                  |
| `translateStatus`         | int         | 正式翻译状态                  |
| `summaryStatus`           | int         | 总结状态                    |
| `summaryImageStatus`      | int/null    | 总结图片状态                  |
| `origLang` / `targetLang` | String/null | 转写源语言 / 翻译目标语言          |

`fileInfo` 关键字段：

| 字段                | 类型            | 说明                               |
| ----------------- | ------------- | -------------------------------- |
| `storageKey`      | NSString/null | 云端加密音频对象 Key；发起转写时作为 `objectKey` |
| `cloudBucketName` | NSString/null | 云存储桶                             |
| `fileName`        | NSString/null | 云端音频文件名                          |
| `cloudFileId`     | NSString/null | 云端文件 ID                          |
| `cloudFileSize`   | long/null     | 云端文件大小，单位字节                      |
| `amplitude`       | NSString/null | 振幅数据                             |

**状态值：根据这个查当前最新的状态**

| 字段                                        | 状态值                                       | 说明      |
| ----------------------------------------- | ----------------------------------------- | ------- |
| `transcriptionStatus` / `translateStatus` | `0` 未处理，`1` 初始化，`2` 处理中，`9` 成功，`100` 失败   | 转写/翻译状态 |
| `summaryStatus`                           | `0`/空 未开始，`1` 初始化，`2` 处理中，`9` 成功，`100` 失败 | 总结状态    |

### 2. 获取转写和翻译结果

`m.wearable.audio.stt.get`

### 3. 获取总结结果

`m.wearable.audio.summary.get`

获取指定录音的标题、总结正文、提纲、关联问题和总结图片地址。

**iOS**

```objectivec
NSDictionary *postData = @{@"key": @"ej_PHONE_IMPORT00BIO7kN_1785149135723"};
[[ThingSmartRequest new] requestWithApiName:@"m.wearable.audio.summary.get"
                                  postData:postData
                                   version:@"1.0"
                                   success:^(id result) {
    // result.title / result.summary / result.outline / result.imageUrl
} failure:^(NSError *error) {
    // 请求失败
}];
```

**Android**

```kotlin
Business().asyncRequest(
    ApiParams("m.wearable.audio.summary.get", "1.0").apply {
        putPostData("key", "ej_PHONE_IMPORT00BIO7kN_1785149135723")
    }, SummaryResultBean::class.java, object : ResultListener<SummaryResultBean> {
        override fun onFailure(bizResponse: BusinessResponse?, bizResult: SummaryResultBean?, apiName: String?) {}
        override fun onSuccess(bizResponse: BusinessResponse?, bizResult: SummaryResultBean?, apiName: String?) {}
    }
)
```

| 字段      | 类型     | 必填  | 说明                 |
| ------- | ------ | --- | ------------------ |
| `key`   | String | 是   | 规范化后的 `recordId`   |
| `devId` | String | 否   | 设备录音时传设备 ID，手机录音省略 |

返回字段：

| 字段         | 类型          | 说明                    |

## 实时文本转 TTS

`m.wearable.audio.tts.text`

传入一段译文文本与其语种，云端实时合成语音并返回一个短时效的 mp3 下载地址。客户端下载音频后自行实现播报。典型场景：用户在对话翻译历史列表中点击某一句，App 取出该句译文调用本接口，播放返回的音频。

> 该接口不校验设备在线状态，设备离线时同样可以调用（播报由手机侧完成）。每次调用独立合成，相同文本重新合成的音色、效果一致。

**iOS**

```objectivec
NSDictionary *postData = @{
    @"text": @"What are those concepts?",
    @"lang": @"en"
};
[[ThingSmartRequest new] requestWithApiName:@"m.wearable.audio.tts.text"
                                  postData:postData
                                   version:@"1.0"
                                   success:^(id result) {
    // result.audioUrl 为 mp3 下载地址，有效期约 5 分钟
} failure:^(NSError *error) {
    // 请求失败
}];
```

**Android**

```kotlin
Business().asyncRequest(
    ApiParams("m.wearable.audio.tts.text", "1.0").apply {
        putPostData("text", "What are those concepts?")
        putPostData("lang", "en")
    },
    TtsResultBean::class.java,
    object : ResultListener<TtsResultBean> {
        override fun onFailure(bizResponse: BusinessResponse?, bizResult: TtsResultBean?, apiName: String?) {}
        override fun onSuccess(bizResponse: BusinessResponse?, bizResult: TtsResultBean?, apiName: String?) {}
    }
)
```

| 参数       | 类型           | 说明                          |
| -------- | ------------ | --------------------------- |
| apiName  | NSString     | `m.wearable.audio.tts.text` |
| postData | NSDictionary | 见下表                         |
| version  | NSString     | 1.0                         |

postData 字段：

| 字段     | 类型       | 必填  | 说明                                            |
| ------ | -------- | --- | --------------------------------------------- |
| `text` | NSString | 是   | 待合成的译文文本，**单次不超过 500 字**，超长将被拒绝；建议按句/段拆分后逐次调用 |
| `lang` | NSString | 是   | 文本语种代码（如 `zh`、`en`），支持清单以联调确认的列表为准            |

返回结构：`result` 包含音频地址信息。

| 字段         | 类型       | 说明                              |
| ---------- | -------- | ------------------------------- |
| `audioUrl` | NSString | mp3 音频下载地址（带访问签名），**有效期约 5 分钟** |
| `expireAt` | long     | 地址过期时间戳（毫秒），据此判断是否需要重新请求        |
| `format`   | NSString | 音频格式，固定 `mp3`                   |

返回示例：

```json
{
  "success": true,
  "t": 1786176000000,
  "result": {
    "audioUrl": "https://xxx.example.com/xxxx.mp3?signature=...",
    "expireAt": 1786176300000,
    "format": "mp3"
  }
}
```

> 音频不作长期存储，云端仅为传输做短暂中转，文件会在短时间内自动清除。如需重复播放，建议客户端下载后自行缓存。

## 设备转写时长查询

`m.wearable.audio.device.usage.get`

传入设备 ID，返回**当前登录用户在该设备上**的本周、本月转写时长（单位：秒），供 App 渲染用量展示。周期边界计算等逻辑全部由云端完成，客户端无需实现任何计算。

> 要求所查询的设备已绑定至当前登录账号（或其所在家庭），查询他人设备将返回权限错误。无需传入时区，云端自动采用设备时区计算周期边界。

**iOS**

```objectivec
NSDictionary *postData = @{@"devId": @"vdevo171642925143326"};
[[ThingSmartRequest new] requestWithApiName:@"m.wearable.audio.device.usage.get"
                                  postData:postData
                                   version:@"1.0"
                                   success:^(id result) {
    // result.weekSeconds / result.monthSeconds 为本周/本月时长（秒）
} failure:^(NSError *error) {
    // 请求失败
}];
```

**Android**

```kotlin
Business().asyncRequest(
    ApiParams("m.wearable.audio.device.usage.get", "1.0").apply {
        putPostData("devId", "vdevo171642925143326")
    },
    UsageResultBean::class.java,
    object : ResultListener<UsageResultBean> {
        override fun onFailure(bizResponse: BusinessResponse?, bizResult: UsageResultBean?, apiName: String?) {}
        override fun onSuccess(bizResponse: BusinessResponse?, bizResult: UsageResultBean?, apiName: String?) {}
    }
)
```

| 参数       | 类型           | 说明                                  |
| -------- | ------------ | ----------------------------------- |
| apiName  | NSString     | `m.wearable.audio.device.usage.get` |
| postData | NSDictionary | `@{@"devId": @"设备ID"}`              |
| version  | NSString     | 1.0                                 |

返回结构：`result` 包含时长统计信息。

| 字段             | 类型       | 说明                               |
| -------------- | -------- | -------------------------------- |
| `weekSeconds`  | long     | 本周转写时长（秒），周期起点为**周一 00:00**      |
| `monthSeconds` | long     | 本月转写时长（秒），周期起点为**自然月 1 日 00:00** |
| `weekStart`    | long     | 本周窗口起点时间戳（毫秒）                    |
| `monthStart`   | long     | 本月窗口起点时间戳（毫秒）                    |
| `endTime`      | long     | 统计窗口终点 = 服务端当前时刻（毫秒）             |
| `timeZone`     | NSString | 本次计算实际采用的时区，如 `Asia/Shanghai`    |

返回示例：

```json
{
  "success": true,
  "t": 1786176000000,
  "result": {
    "weekSeconds": 1860,
    "monthSeconds": 7230,
    "weekStart": 1785945600000,
    "monthStart": 1785513600000,
    "endTime": 1786176000000,
    "timeZone": "Asia/Shanghai"
  }
}
```

统计口径：

| 口径项    | 约定                                                 |
| ------ | -------------------------------------------------- |
| 时长定义   | **物理时长**：实时转写按会话实际时长计；音频文件转写按音频实际时长计               |
| 统计范围   | 当前登录用户在该设备上产生的转写；实时转写与文件转写**分别计入**                 |
| 已删除记录  | **计入**（转写行为已发生，不因删除记录而扣减）                          |
| 失败任务   | 不计入（仅统计成功完成的转写）                                    |
| 进行中的会话 | 结束后计入                                              |
| 周期边界   | 周 = 周一 00:00 起；月 = 自然月 1 日 00:00 起；按 `timeZone` 计算 |

## 录音标签接口

标签接口以 `recordId` 标识录音，用户身份从登录上下文获取。以下接口是当前 Native/APP 标签链路实际使用的云端接口；标签库管理、批量绑定等内部接口不属于对外接入范围。

### 公共约定

| 项目     | 约定                                       |
| ------ | ---------------------------------------- |
| API 版本 | `1.0`                                    |
| 登录要求   | 必须登录，标签按当前用户隔离                           |
| 单条录音上限 | 10 个有效标签，手动标签优先占用名额                      |
| 标签长度   | 最多 100 个字符；服务端会校验非法字符与空标签                |
| 标签来源   | `tagSource=0` AI 生成；`tagSource=1` 用户手动添加 |
| 排序     | `sortOrder` 越小越靠前                        |

### 1. 查询录音标签

| 项目  | 内容                          |
| --- | --------------------------- |
| API | `m.wearable.audio.tag.list` |
| 版本  | `1.0`                       |
| 用途  | 查询指定录音的全部有效标签               |

请求参数：

| 字段         | 类型       | 必填  | 说明       |
| ---------- | -------- | --- | -------- |
| `recordId` | `string` | 是   | 业务录音唯一标识 |

```json
{"recordId":"record_123456"}
```

业务结果为标签对象数组：

```json
[
  {"tag":"客户拜访","tagSource":1,"sortOrder":0},
  {"tag":"重点事项","tagSource":0,"sortOrder":1}
]
```

| 字段          | 类型        | 说明             |
| ----------- | --------- | -------------- |
| `tag`       | `string`  | 标签名称           |
| `tagSource` | `integer` | 0 AI 生成，1 手动添加 |
| `sortOrder` | `integer` | 排序序号，数值越小越靠前   |

无标签时返回空数组。

### 2. 新增录音标签

| 项目   | 内容                         |
| ---- | -------------------------- |
| API  | `m.wearable.audio.tag.add` |
| 版本   | `1.0`                      |
| 用途   | 为指定录音手动新增一个标签              |
| 业务返回 | `boolean`，成功为 `true`       |

| 字段         | 类型       | 必填  | 说明     |
| ---------- | -------- | --- | ------ |
| `recordId` | `string` | 是   | 标签所属录音 |
| `tag`      | `string` | 是   | 单个标签名称 |

```json
{"recordId":"record_123456","tag":"客户拜访"}
```

服务端校验标签文本、数量和重复项；新增标签来源固定为手动，排序位置追加到当前末尾。成功后更新搜索索引、录音修改时间，并尝试发送标签变更通知。

### 3. 删除录音标签

| 项目   | 内容                            |
| ---- | ----------------------------- |
| API  | `m.wearable.audio.tag.delete` |
| 版本   | `1.0`                         |
| 用途   | 删除单个标签或清空录音标签                 |
| 业务返回 | `boolean`，成功为 `true`          |

| 字段         | 类型       | 必填  | 说明            |
| ---------- | -------- | --- | ------------- |
| `recordId` | `string` | 是   | 标签所属录音        |
| `tag`      | `string` | 否   | 不传或为空表示清空全部标签 |

单个删除：

```json
{"recordId":"record_123456","tag":"客户拜访"}
```

清空全部：

```json
{"recordId":"record_123456"}
```

删除采用软删除；删除不存在的标签仍按成功处理。清空能力由云端提供，但当前 Native/TTT 标签更新入口只提交单个标签，不应使用空数组模拟清空。

### 4. 更新标签排序

| 项目   | 内容                            |
| ---- | ----------------------------- |
| API  | `m.wearable.audio.tag.update` |
| 版本   | `1.0`                         |
| 用途   | 更新指定录音的标签显示顺序                 |
| 业务返回 | `boolean`，成功为 `true`          |

| 字段         | 类型       | 必填  | 说明                              |
| ---------- | -------- | --- | ------------------------------- |
| `recordId` | `string` | 是   | 标签所属录音                          |
| `tags`     | `string` | 是   | 完整标签数组序列化后的 JSON 字符串，不是 JSON 数组 |

```json
{"recordId":"record_123456","tags":"[\"A级客户\",\"客户拜访\",\"产品需求\"]"}
```

服务端解析 `tags` 后按数组下标写入 `sortOrder`。调用方必须传当前录音的完整标签列表；空数组返回成功但不改变已有顺序。

### 5. 查询历史标签

| 项目       | 内容                                        |
| -------- | ----------------------------------------- |
| ATOP API | `m.wearable.audio.tag.history`            |
| REST 映射  | `GET /v1.0/m/wearable/audio/tags/history` |
| 版本       | `1.0`                                     |
| 用途       | 查询当前用户曾使用过的手动标签                           |

该接口无需业务请求参数，用户身份从登录上下文取得。业务结果为最多 30 个去重后的 `string` 标签名称，按最近创建记录时间倒序；可能包含已软删除的历史标签，不包含 AI 标签。

```json
["客户拜访","A级客户","产品需求"]
```

### 6. 标签接入时序

1. Native 页面从文件详情读取 `recordId` 和 `tags`，以详情数据作为当前展示快照。
2. 新增、删除、排序分别调用 Native 的 `updateRecordTagResult:`，由 APP 调用上述云端接口并落库本地 `tags`。
3. 只有云端和本地落库都成功，Native 回调才应视为成功；失败时重新查询详情恢复一致性。
4. AI 总结生成标签后，云端只替换 AI 来源标签，不删除手动标签；页面应重新查询详情。
5. 多端同步通知仅作为刷新信号，最终以 `m.wearable.audio.tag.list` 或文件详情结果为准。

### 7. 标签错误码

| 错误码                       | 含义       | 典型触发条件                      |
| ------------------------- | -------- | --------------------------- |
| `PARAMS_INVALID`          | 参数无效     | `recordId`、标签或排序 JSON 为空/非法 |
| `NOTE_TAG_TOO_LONG`       | 标签过长     | 标签超过 100 个字符                |
| `NOTE_TAG_INVALID_CHAR`   | 标签包含非法字符 | 特殊字符、控制字符或不可见字符             |
| `NOTE_TAG_LIMIT_EXCEEDED` | 标签数量超限   | 当前录音已有 10 个有效标签             |
| `NOTE_TAG_ALREADY_EXISTS` | 标签已存在    | 同一录音已有同名有效标签                |

云端错误会沿用统一网关响应格式；Native/TTT 可能进一步映射错误码，但排查时应保留服务端错误信息。

## 错误处理

| 错误场景  | errorCode                     | 触发条件                     | 处理建议               |
| ----- | ----------------------------- | ------------------------ | ------------------ |
| 文本超长  | 参数校验类错误                       | TTS 接口 `text` 超过 500 字   | 按句分段后逐次调用          |
| 参数缺失  | 参数校验类错误                       | 必填参数为空                   | 检查调用参数             |
| 语种不支持 | `TRANSCRIBE_LANG_NOT_SUPPORT` | TTS 接口传入的 `lang` 不在支持清单内 | 提示暂不支持该语种          |
| 合成失败  | `TTS_SYNTHESIZE_FAILED`       | 云端合成异常                   | 可重试 1 次；仍失败则提示稍后再试 |
| 无设备权限 | `PERMISSION_DENY`             | 时长查询接口查询非本账号名下设备         | 检查设备与账号绑定关系        |
| 设备不存在 | 设备类错误                         | `devId` 不存在或已解绑          | 刷新设备列表后重试          |
| 系统繁忙  | 网关标准错误                        | 限流、超时等                   | 指数退避重试（如 1s / 3s）  |

> **重试原则**：各接口均为幂等调用，可安全重试；但 TTS 接口每次调用都会产生一次真实合成，建议至多重试 1 次，避免对同一内容的高频重复请求。
