Native SDK 核心接入流程

添加依赖

在 Podfile 中引入 Native SDK 模块：

pod 'TUniAudioDetectManager'

获取单例

线程安全单例，不支持 init / new：

#import <TUniAudioDetectManager/ThingAudioDetectManagerNative.h>

id<ThingAudioDetectManagerNativeProtocol> manager =
    [ThingAudioDetectManagerNative sharedInstance];

完成登录与家庭初始化

涂鸦 SDK 以「家庭」为维度管理设备和权限，录音前需确保用户已登录且至少有一个家庭。

开始录音

先查询是否有活动任务，避免重复开始；然后配置参数并启动：

// 查询活动任务
ThingAudioRecordObject *task = [manager recordTransferTaskWithDeviceId:deviceId];

ThingAudioRecordConfig *config = [[ThingAudioRecordConfig alloc] init];
config.recordType = ThingAudioRecordTypeMeet;
config.transferType = ThingAudioRecordTransferTypeRealTime;
config.needAsr = YES;
config.needTranslate = YES;
config.originalLanguage = @"zh";
config.targetLanguage = @"en";

[manager startAudioRecordingWithDeviceId:deviceId
                                  config:config
                                 success:^(ThingAudioRecordObject *task) {
    NSLog(@"录音开始 recordId=%@", task.recordId);
} failure:^(NSError *error) {
    NSLog(@"录音失败 %@", error);
}];

注册监听器接收实时回调

按 deviceId 注册，销毁前必须用同一实例移除：

[manager addRecordListener:self deviceId:deviceId];
[manager removeRecordListener:self deviceId:deviceId]; // dealloc

查询录音列表与详情

录音结束后文件入库，可通过列表查询和详情接口获取：

ThingAudioRecordFilesParams *params = [[ThingAudioRecordFilesParams alloc] init];
params.orderBy = @(1);  // 按录音时间
params.asc = @(0);      // 降序
[manager getRecordTransferResultList:params success:^(NSArray *list) {
    NSLog(@"共 %lu 条录音", (unsigned long)list.count);
} failure:^(NSError *error) { ... }];
⚠️ 关键提醒

开始录音前先调用 recordTransferTaskWithDeviceId: 查任务，避免同一设备重复开始。区分 recordId（业务录音 ID）与 fileId（本地文件主键）——详情/分享/下载用前者，转写/总结/删除用后者。

快速开始 / 基础约定

基础约定

SDK 使用前需要了解的类型、ID 和错误处理机制

🔁 回调类型

类型定义含义
Successvoid(^)(void)操作成功，无返回数据
Failurevoid(^)(NSError *)操作失败，error.code 为错误码

标记 nullable 的回调可传 nil。回调线程由底层决定，更新 UI 需切回主线程。

🔑 关键 ID

接入时最容易混淆的 4 个 ID，请务必区分使用场景：

deviceId
NSString
录音设备标识。录音控制、监听器注册均按此隔离
recordId
NSString
业务录音唯一标识。用于详情、分享、标签、云端下载
fileId
long long
本地文件主键。用于转写、总结、更新、删除
asrId
long long
实时 ASR 分句 ID。用于查询/更新单句识别结果

⚠️ 错误处理

错误域为 ThingAudioDetectManagerNativeErrorDomain。

  • 错误码 1：底层 ThingModule 服务未注册或不可用
  • 其余错误码：透传底层 SDK 的 NSError

转写 / 总结 / 翻译

SDK 发起任务；结果可通过 Native Delegate 或云端查询获取

flowchart TB A["准备 fileId + recordId"] --> B["addSyncListener:self"] B --> C["组装 params + taskType"] C --> D["processRecordTransferResult"] D --> E{"请求结果"} E -- "failure" --> F["处理 NSError / 重试"] E -- "success" --> G["等待 uploadStatusResult:"] G --> H["按 item.recordId 过滤"] H --> I{"处理状态"} I -- "处理中" --> G I -- "成功" --> J["调用 Native 结果查询接口"] I -- "失败" --> F J --> K["展示转写 / 总结 / 翻译结果"] K --> L["removeSyncListener:self"] F --> L

方式一：SDK 发起 + Native Delegate 监听 + SDK 结果查询

发起统一走 SDK，结果有两种获取方式

processRecordTransferResult:taskType:progress:success:failure: 始终用于发起转写、总结和翻译。success 只表示请求已提交；结果可以使用 ThingAudioRecordSyncManagerDelegate 监听，也可以使用云端查询接口轮询状态和读取结果。

🧭 Native 发起规则

统一由 SDK 发起

转写、总结和翻译都调用 processRecordTransferResult:taskType:progress:success:failure:，不通过云端发起接口。

保存两个 ID

使用 fileId 组装 Native 参数和查询 SDK 结果；使用 recordId 过滤 Delegate 状态或作为云端查询的 key。

保证正式转写先完成

总结和翻译依赖正式转写。transferStatus != 2 时先发起转写，等待成功后再继续。

结果获取二选一

可监听 uploadStatusResult: 后调用 SDK 查询；也可查询云端详情状态，成功后调用 stt.get 或 summary.get。

processRecordTransferResult:taskType:progress:success:failure:
发起离线处理任务（转写/总结/翻译） 异步
▶
- (nullable NSString *)processRecordTransferResult:(ThingAudioRecordUploadFileParams *)params
                             taskType:(NSInteger)taskType
                             progress:(void(^)(double progress, int status))progress
                              success:(ThingAudioDetectNativeSuccess)success
                              failure:(ThingAudioDetectNativeFailure)failure;

progress 仅用于转写任务的文件上传进度，回调中的 status 是底层上传状态（0 开始、1 更新、2 结束、3 取消）；二者都不是 AI 最终完成事件。同步返回值是转写任务 ID；总结和翻译返回 nil。success 只表示请求已提交。

taskType含义
0转写
1总结
2翻译
ThingAudioRecordUploadFileParams 字段
字段类型说明
fileIdlong long待处理文件 ID
recordIdNSString业务录音 ID
languageNSStringASR 倾向识别语言

0 转写fileId、recordId、language、enableSpeakerlanguage 只是 ASR 倾向语言；enableSpeaker 控制说话人识别
1 总结fileId、recordId、summaryLang；可选 templateCodesummaryLang 是总结输出语言；templateCode 为模板编码，nil 使用默认模板

ThingAudioRecordSyncManagerDelegate
SDK 方式监听转写、总结、翻译最终状态 SDK 方式
▶
@interface RecordDetailViewController () <ThingAudioRecordSyncManagerDelegate>
@property (nonatomic, assign) long long fileId;
@property (nonatomic, copy) NSString *recordId;
@end

- (void)viewDidLoad {
    [super viewDidLoad];
    [[ThingAudioDetectManagerNative sharedInstance] addSyncListener:self];
}

- (void)dealloc {
    [[ThingAudioDetectManagerNative sharedInstance] removeSyncListener:self];
}

- (void)uploadStatusResult:(ThingFileUpdateStatusResult *)result {
    for (ThingFileUpdateStatusItem *item in result.items) {
        if (![item.recordId isEqualToString:self.recordId]) continue;
        dispatch_async(dispatch_get_main_queue(), ^{
            if (item.transferStatus == 2) [self loadRecognizeResult];
            if (item.summaryStatus == 3) [self loadSummaryResult];
            if (item.translateStatus == 2) [self loadRecognizeResult];
            // transferStatus == 3、summaryStatus == 4、translateStatus == 3 时展示失败和重试入口
        });
    }
}

回调线程不固定，更新 UI 前必须切换到主线程。items 可能包含多条录音，必须逐项按 recordId 过滤。

字段状态值处理
transferStatus0 未转写，1 处理中，2 成功，3 失败成功后查询正式转写
summaryStatus0 旧数据，1 未总结，2 处理中，3 成功，4 失败成功后查询总结结果
translateStatus0 未翻译，1 处理中，2 成功，3 失败成功后重新查询正式转写中的译文

状态事件只关注 transferStatus、summaryStatus 和 translateStatus；失败项不包含 NSError，调用方应展示对应失败状态并按 taskType 重试。

📖 SDK 结果查询接口

方法参数返回
getRecordTransferRecognizeResultfileId正式转写结果；翻译成功后也调用此方法获取译文
getRecordTransferSummaryResultfileIdNSString * 总结文本

只有对应状态进入成功值后才查询结果。状态事件的失败项不包含 NSError；请求阶段错误由接口的 failure 返回底层 NSError。

☁️ 云端查询获取结果

发起转写、总结、翻译仍使用 Native SDK；本链路只使用云端接口查询状态和最终结果，不调用云端发起接口。

flowchart TB A["SDK processRecordTransferResult"] --> B["请求 success：仅表示已提交"] B --> C["m.wearable.audio.record.detail.query"] C --> D{"云端状态"} D -- "处理中" --> C D -- "transcriptionStatus = 9" --> E["m.wearable.audio.stt.get"] D -- "translateStatus = 9" --> E D -- "summaryStatus = 9" --> F["m.wearable.audio.summary.get"] E --> G["读取 transcript / translation"] F --> H["读取 summary / outline / imageUrl"]

方式二：SDK 发起 + 云端详情状态查询 + 云端结果查询

1. 先使用 SDK 发起

调用 processRecordTransferResult:taskType:progress:success:failure:，根据 taskType 区分转写、总结和翻译。

2. 查询云端详情状态

调用 m.wearable.audio.record.detail.query，传入 recordId；云端 AI 接口使用同一个值作为 key。

3. 查询正式结果

转写或翻译成功后调用 m.wearable.audio.stt.get；总结成功后调用 m.wearable.audio.summary.get。

@interface RecordProcessViewController () <ThingAudioRecordSyncManagerDelegate>
@property (nonatomic, assign) long long fileId;
@property (nonatomic, copy) NSString *recordId;
@end

- (void)viewDidAppear:(BOOL)animated {
    [super viewDidAppear:animated];
    [[ThingAudioDetectManagerNative sharedInstance] addSyncListener:self];
    [self reloadDetail];
}

- (void)viewWillDisappear:(BOOL)animated {
    [super viewWillDisappear:animated];
    [[ThingAudioDetectManagerNative sharedInstance] removeSyncListener:self];
}

- (void)startTask:(NSInteger)taskType {
    ThingAudioRecordUploadFileParams *params = [ThingAudioRecordUploadFileParams new];
    params.fileId = self.fileId;       // 任务/结果接口使用
    params.recordId = self.recordId;   // 状态事件过滤使用
    params.language = @"zh";          // ASR 倾向语言
    params.enableSpeaker = NO;        // 说话人识别
    if (taskType == 1) {
        params.summaryLang = @"zh";
        params.templateCode = nil;    // 默认总结模板
    } else if (taskType == 2) {
        params.transLang = @"en";     // 翻译目标语言
    }

    [[ThingAudioDetectManagerNative sharedInstance]
        processRecordTransferResult:params taskType:taskType
        progress:^(double progress, int status) {
            dispatch_async(dispatch_get_main_queue(), ^{
                [self showStatus:[NSString stringWithFormat:@"文件上传中 %.0f%%（status=%d）", progress, status]];
            });
        } success:^{
            // 只表示请求已提交，最终状态等待 uploadStatusResult:
        } failure:^(NSError *error) {
            [self showStatus:error.localizedDescription];
        }];
}

- (void)uploadStatusResult:(ThingFileUpdateStatusResult *)result {
    dispatch_async(dispatch_get_main_queue(), ^{
        for (ThingFileUpdateStatusItem *item in result.items) {
            if (![item.recordId isEqualToString:self.recordId]) continue;
            if (item.transferStatus == 2) [self fetchRecognizeResult];
            if (item.summaryStatus == 3) [self fetchSummaryResult];
            if (item.translateStatus == 2) [self fetchRecognizeResult];
            if (item.transferStatus == 3 || item.summaryStatus == 4 || item.translateStatus == 3) {
                [self showStatus:@"AI 处理失败，可按对应 taskType 重试"];
            }
        }
    });
}

- (void)fetchRecognizeResult {
    [[ThingAudioDetectManagerNative sharedInstance]
        getRecordTransferRecognizeResult:self.fileId
        success:^(NSString *text) { [self showText:text]; }
        failure:^(NSError *error) { [self showStatus:error.localizedDescription]; }];
}

- (void)fetchSummaryResult {
    [[ThingAudioDetectManagerNative sharedInstance]
        getRecordTransferSummaryResult:self.fileId
        success:^(NSString *text) { [self showText:text]; }
        failure:^(NSError *error) { [self showStatus:error.localizedDescription]; }];
}
