设备区间转写时长查询接口 · 接入简介

API：m.wearable.audio.device.usage.range v1.0 协议：ATOP（Fusion），C 端登录 日期：2026-09-11 详细设计：《绿联耳机转写时长区间查询接口-技术方案》

查询当前登录用户在指定设备上、任意起止区间内的转写物理总时长（秒）。与「本周/本月查询」（m.wearable.audio.device.usage.get）同一套统计口径：离线转写音频物理时长（仅成功完成）+ 实时转写会话物理时长；含已删除记录；同一音频两种转写各计一次。

1核心规则

  • 任意历史区间均可查：不限制区间距今多远，只要求跨度 ≤ 1 年（endTime ≤ startTime + 1年，日历语义）；
  • 不允许查未来：endTime > 当前时刻 返回错误；
  • 仅可查自己名下设备：非设备所在家庭成员返回 PERMISSION_DENY。

2入参

参数类型必填说明
devIdString是设备 ID
startTimeLong是开始时间，epoch 毫秒（含）
endTimeLong是结束时间，epoch 毫秒（含）；须满足 startTime < endTime ≤ startTime+1年 且不晚于当前时刻
timeZoneIdString否App 时区（网关系统参数自动注入）；不影响统计结果，仅作设备时区缺失时的降级与回显

3出参

字段类型说明
totalSecondsLong区间内转写物理总时长（秒）
startTimeLong回显请求的区间起点（epoch 毫秒）
endTimeLong回显请求的区间终点（epoch 毫秒）
timeZoneString实际采用的时区 ID（回显）

4错误码

errorCode触发条件客户端处理
USAGE_TIME_RANGE_INVALIDstartTime/endTime 缺失，或 startTime ≥ endTime提示"时间参数有误"
USAGE_TIME_RANGE_OVER_LIMIT跨度超一年，或 endTime 晚于当前时刻toast「单次最多查询一年的转写时长」，并限制日期选择器跨度
PERMISSION_DENY当前用户非设备所在家庭成员提示无权限查看该设备
框架缺参 / not-exists 信封devId 缺失 / 设备不存在或非正常状态按框架标准错误处理

5报文示例

请求：

{
  "devId": "6c52afyjzzovrglu",
  "startTime": 1756684800000,
  "endTime": 1759276800000
}

成功响应：

{
  "success": true,
  "result": {
    "totalSeconds": 3265,
    "startTime": 1756684800000,
    "endTime": 1759276800000,
    "timeZone": "Asia/Shanghai"
  }
}

失败响应（超限 / 参数非法 / 无权限同结构）：

{
  "success": false,
  "errorCode": "USAGE_TIME_RANGE_OVER_LIMIT",
  "errorMsg": "time range exceeds one year or ends in the future"
}
时间入参一律用 epoch 毫秒（绝对时间戳，与时区无关）；日期选择器请在客户端限制可选跨度为一年，避免无效请求。错误信封字段名以联调时网关实际报文为准。
