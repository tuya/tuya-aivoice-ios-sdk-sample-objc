# BT 设备激活接入指南

## 头文件导入

```objc
#import <ThingSmartDeviceCoreKit/ThingSmartBTService.h>
#import <ThingSmartDeviceKit/ThingSmartDeviceKit.h>  // ThingSmartDeviceModel
```

## 步骤一：获取已连接的 BT 设备

调用 `ThingSmartBTService` 的 `getConnectedBluetoothDevices` 方法，获取当前系统已连接的蓝牙设备列表。

```objc
NSArray<ThingSmartBTModel *> *list = [[ThingSmartBTService shareInstance] getConnectedBluetoothDevices];
```

返回值为 `ThingSmartBTModel` 数组，每个 model 包含以下属性：

| 属性 | 类型 | 说明 |
|------|------|------|
| `name` | `NSString` | 设备蓝牙名称 |
| `mac` | `NSString` | 设备 MAC 地址 |
| `type` | `NSString` | 设备类型 |

## 步骤二：激活未授权的 BT 设备

### 2.1 构造激活参数

使用 `ThingSmartBTActiveWithoutUUIDParam` 构造激活参数：

```objc
ThingSmartBTActiveWithoutUUIDParam *params = [[ThingSmartBTActiveWithoutUUIDParam alloc] init];
params.productKey = @"你的productKey";   // 产品 productKey
params.btName     = btModel.name;        // 从步骤一获取的设备蓝牙名称
params.homeId     = currentHomeId;       // 当前家庭 ID
params.mac        = btModel.mac;         // 从步骤一获取的设备 MAC 地址
```

参数说明：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `productKey` | `NSString` | 是 | 涂鸦 IoT 平台上创建产品时获取的 productKey |
| `btName` | `NSString` | 是 | 设备蓝牙名称，来自步骤一的 `ThingSmartBTModel.name` |
| `homeId` | `long long` | 是 | 要绑定到的家庭 ID |
| `mac` | `NSString` | 是 | 设备 MAC 地址，来自步骤一的 `ThingSmartBTModel.mac` |

### 2.2 调用激活方法

```objc
[[ThingSmartBTService shareInstance] activeBTDeviceWithoutUUIDParams:params
    success:^(ThingSmartDeviceModel * _Nonnull deviceModel) {
        // 激活成功，deviceModel.devId 为设备 ID
        NSLog(@"激活成功，devId: %@", deviceModel.devId);

        // （可选）更新设备蓝牙名称
        [[ThingSmartBTService shareInstance] updateBTName:btModel.name
                                                   devId:deviceModel.devId
                                                 success:^{
            NSLog(@"更新名称成功");
        } failure:^(NSError *error) {
            NSLog(@"更新名称失败: %@", error);
        }];
    }
    failure:^(NSError *error) {
        // 激活失败
        NSLog(@"激活失败: %@", error);
    }];
```

### 2.3 回调说明

| 回调 | 参数 | 说明 |
|------|------|------|
| `success` | `ThingSmartDeviceModel *deviceModel` | 激活成功，通过 `deviceModel.devId` 获取设备 ID |
| `failure` | `NSError *error` | 激活失败，`error` 中包含错误码和错误描述 |

## 完整示例

```objc
#import <ThingSmartDeviceCoreKit/ThingSmartBTService.h>
#import <ThingSmartDeviceKit/ThingSmartDeviceKit.h>

// 1. 获取已连接 BT 设备
NSArray<ThingSmartBTModel *> *list = [[ThingSmartBTService shareInstance] getConnectedBluetoothDevices];

// 2. 选择一个设备进行激活
ThingSmartBTModel *btModel = list.firstObject;
if (!btModel) return;

// 3. 构造参数并激活
ThingSmartBTActiveWithoutUUIDParam *params = [[ThingSmartBTActiveWithoutUUIDParam alloc] init];
params.productKey = @"你的productKey";
params.btName     = btModel.name;
params.homeId     = currentHomeId;
params.mac        = btModel.mac;

[[ThingSmartBTService shareInstance] activeBTDeviceWithoutUUIDParams:params
    success:^(ThingSmartDeviceModel * _Nonnull deviceModel) {
        NSLog(@"激活成功，devId: %@", deviceModel.devId);

        [[ThingSmartBTService shareInstance] updateBTName:btModel.name
                                                   devId:deviceModel.devId
                                                 success:^{
            NSLog(@"设备名称更新成功");
        } failure:^(NSError *error) {
            NSLog(@"设备名称更新失败，但激活已成功");
        }];
    }
    failure:^(NSError *error) {
        NSLog(@"激活失败: %@", error);
    }];
```

## 涉及的类与方法速查

| 类 | 方法 | 用途 |
|----|------|------|
| `ThingSmartBTService` | `+shareInstance` | 获取单例 |
| `ThingSmartBTService` | `-getConnectedBluetoothDevices` | 获取已连接 BT 设备列表 |
| `ThingSmartBTService` | `-activeBTDeviceWithoutUUIDParams:success:failure:` | 激活未授权 BT 设备 |
| `ThingSmartBTService` | `-updateBTName:devId:success:failure:` | 更新设备蓝牙名称（可选） |
| `ThingSmartBTActiveWithoutUUIDParam` | 参数对象 | 激活参数（productKey / btName / homeId / mac） |
| `ThingSmartBTModel` | 数据模型 | BT 设备信息（name / mac / type） |
